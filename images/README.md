## Quick start

1. Open any project page in your browser — each grey box shows a filename like `ccp-hifi-login.jpg`.
2. Save your image with that **exact name** and put it in this `images/` folder (or the path noted on the page).
3. Tell me in chat: *"I uploaded the images"* — I can wire `<img src="...">` tags if filenames differ.

You can also **drag images into Cursor chat** or attach a ZIP — share the mapping (e.g. "box 3 = my dashboard screenshot") and I’ll rename and link them.
