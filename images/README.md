# Image naming guide

Replace grey placeholder boxes by adding files with these exact names to this folder.
Then update the HTML to use `<img src="images/filename.jpg" alt="...">` instead of placeholders.

## Home page (`index.html`)
- `hero-portrait.jpg` — Your portrait in the hero section
- `icon-linkedin.svg` — LinkedIn icon in footer
- `icon-email.svg` — Email icon in footer

## About page (`about.html`)
- `about-portrait.jpg` — Portrait on about page
